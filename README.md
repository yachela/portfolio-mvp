# Portfolio de Laura Belén Yachelini

Sitio personal estático construido con [Astro](https://astro.build), sin APIs de runtime, analítica ni scripts remotos.

## Desarrollo local

```bash
pnpm install
pnpm dev
```

## Validación y build

```bash
pnpm check
pnpm build
```

El CV enlaza a `public/cv/laura-yachelini-cv.pdf`, un placeholder local para reemplazar cuando el archivo final esté disponible. No se incluyen URLs inventadas para proyectos ni servicios externos.
